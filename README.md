# Bionic Butterfly — Solution Design

## Project Status
Phase: P1 — Technical Research
Design Status: DRAFT

## Project Goal
Develop a bio-inspired flapping-wing butterfly robot.

## Reference Projects
- ESP-FLUTTER
- S-DiY Bionic Butterfly

## Design Workflow
1. Analyze reference projects and videos.
2. Document functional and hardware requirements.
3. Review architecture and control strategy.
4. Approve design before assigning coding tasks.
5. Review implementation through Pull Requests.

## Design Rules
- Design changes must be committed.
- AI coding tasks require approved design.
- Source implementation belongs to AI Code.
- PR review must use an isolated checkout.
